# 5-Build
Module 5 Build is a multi-page website for Indie Film Collective.
The website contains information about screenings, workshops, collaboration, and volunteer opportunities
The HTML is semantic and validated.
CSS is responsive.  Mobile first layout use.
There is no Javascript.
There are a total of 5 .html pages that include index.html, screenings.html, workshops.html, collaborations.html and volunteer.html.
There are a total of 1 .css page that includes styles.css.
